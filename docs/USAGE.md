# 安装与使用教程

[返回软件介绍](../README.md) · [常见问题](FAQ.md) · [HG阿伟官网资源库](https://www.hgawei.cn/software)

微信搜索公众号 **「HG阿伟」** 并关注，获取软件使用说明与更新消息。本教程根据 **v0.1.6** 整理，界面与下载渠道以实际安装版本为准。

## 1. 下载和打开软件

现有发布版本：[v0.1.6 Windows x64 安装包](https://www.hgawei.cn/api/v1/desktop/updates/be1cd0cd-5b77-452c-868c-549b0007d2f7/installer)。后续版本请关注公众号消息和 [官网资源库](https://www.hgawei.cn/software)。

- 安装版：运行安装程序，按向导完成后打开「微信视频号下载器」。
- 便携版：完整解压，运行 `wechat-video-desktop.exe`。不要只复制主程序，也不要直接在压缩包里打开。

需要 Windows 10/11 64 位、电脑微信和可用网络。运行软件无需配置开发环境。缺少界面组件时，软件会按需准备。

## 2. 连接电脑微信

1. 登录电脑微信，打开视频下载器。
2. 等待在线启动检查通过，再点击「连接微信」。
3. 首次使用按 Windows 提示完成确认，不需要自己查找证书文件或手动导入。
4. 打开电脑微信的视频号页面，保持页面打开，等待下载器显示已连接。

已经完成首次准备的电脑，软件可能自动连接。若一直等待页面，重新打开电脑微信中的视频号，再按界面提示重连。

软件连接时会临时使用系统代理与微信页面通信，正常断开会恢复连接前的代理设置。若同时使用其他代理软件，遇到网络异常时先在下载器中断开连接，再检查原有网络设置。

## 3. 找到需要的作品

| 入口 | 使用方式 |
| --- | --- |
| 我的关注 | 查看当前微信账号关注的作者，选择作者进入作品列表；需要更多作者时继续加载 |
| 搜索作者 | 输入名称，点击对应作者；同名作者需要根据头像、简介等信息区分 |
| 粘贴链接 | 复制一条软件支持的视频号分享链接，粘贴后解析作品 |

作者列表或关注接口异常时，按页面提示刷新或重试。没有加载出结果不等于账号确实没有关注或没有作品。

## 4. 筛选、清晰度和保存目录

在作者作品列表中可按标题关键词和发布日期筛选。点击「加载更多作品」继续查看后续内容。

清晰度有「最高可用清晰度」和「默认原始规格」。能取得的规格由作品本身提供，最高可用不保证固定分辨率。

确认默认保存目录。首页和设置都可以更改；更改只影响后续任务，已有任务仍显示各自使用的目录。

## 5. 下载选中的作品

1. 在作品列表勾选需要的视频。
2. 核对已选数量、保存目录和清晰度。
3. 点击「下载选中」。
4. 进入「下载中心」查看任务状态和进度。

「全选已加载作品」针对当前已加载并可选择的作品，不会自动等同于作者全部作品。

## 6. 下载作者全部作品

1. 选择目标作者，按需设置标题关键词和日期范围。
2. 点击「下载作者全部作品」。
3. 在确认窗口核对作者、筛选条件和清晰度。
4. 点击「开始批量下载」。

软件会继续获取后续分页，下载符合条件的可访问作品，包括还未在当前列表显示的作品。可在下载中心暂停或继续批次。

「作品获取完成」表示本次可访问接口的分页结束，不保证含全部历史或已删除内容。

## 7. 查看文件、暂停和继续

![下载中心界面预览，未连接且没有任务](../images/01-download-center.png)

*图为 v0.1.6 浏览器界面预览，连接与下载请在桌面软件中使用。*

在下载中心可以：

- 切换「全部」「进行中」「已完成」「未完成」查看对应任务。
- 暂停单个任务、暂停批次或暂停全部任务。
- 对未完成的任务点击继续或重试。
- 点击任务的「打开保存目录」查看文件夹，完成后点击「定位文件」。

每条任务下方显示它实际使用的保存位置。默认目录与旧任务目录不同时，以任务自身显示为准。

重启后先等待在线检查，按需连接微信，再手动继续任务。已经完成且文件完整的结果可跳过；文件被移动、删除或不完整时，任务可能需要重新处理。

## 8. 更新和反馈

在「设置」中检查软件更新。下载安装包后，按软件提示确认安装；安装前会暂停任务并退出软件。

「给作者留言」可以提交使用问题和建议，回复在同一台电脑的「我的留言」查看。

也可以关注微信公众号 **「HG阿伟」**，或访问 [官网资源库](https://www.hgawei.cn/software) 获取消息。
