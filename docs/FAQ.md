已有 [v0.1.6 Windows x64 安装包](https://www.hgawei.cn/api/v1/desktop/updates/be1cd0cd-5b77-452c-868c-549b0007d2f7/installer)。这是现有发布版本，不保证始终为最新版。后续消息请关注公众号「HG阿伟」及 [官网资源库](https://www.hgawei.cn/software)。

## 支持哪些系统？需要 Python 吗？

这里介绍的是 Windows 10/11 64 位桌面版。需要已登录的电脑微信和网络，运行不需要安装 Python、Node.js、Rust 或 Go。缺少 WebView2 界面组件时，软件按需准备。

## 和公众号文章下载器有什么区别？

视频版保存视频号作品；公众号文章版用于图文归档，支持 HTML、Markdown、TXT、DOCX、PDF、MHTML 等格式。

需要图文版请查看 [微信公众号下载器](https://github.com/ghgdzw/wechat-download) 或 [官网下载页](https://www.hgawei.cn/software/b5cf1519-1161-443a-b2da-393d0b79de0f)。

## 为什么软件打开后不能连接或下载？

先等待在线启动检查通过。检查失败、当前版本不可用或要求更新时，按界面提示处理。然后确认电脑微信已登录，点击「连接微信」，打开电脑微信中的视频号页面。

首次使用需按 Windows 提示完成准备。外部浏览器页面不能替代电脑微信中的视频号页面。

## 一直显示等待微信页面怎么办？

关闭旧的视频号窗口，重新打开电脑微信的视频号页面，保持打开，再按下载器提示重新连接。只打开微信聊天主窗口，不一定已经建立视频号页面连接。

如果曾同时开启多个下载器，先退出旧实例，再使用当前版本。仍有问题时反馈版本、操作步骤和界面提示。

## 为什么「我的关注」为空或作者搜索失败？

先检查微信页面是否已连接，确认当前登录的微信账号，再尝试刷新、重新连接或稍后重试。接口错误与真实空列表是不同情况，按界面提示判断。

关注列表属于当前微信账号；不要把上一次页面显示的结果当成切换账号后的结果。

## 「全选」就是下载作者全部作品吗？

「全选已加载作品」只针对当前已经加载并可选择的作品。「下载作者全部作品」会继续获取后续分页，并按你设定的筛选条件处理作品。

全部作品下载也仅限本次微信接口可访问的内容，不保证取得已删除、私密、受限内容或全部历史。

## 可以选择清晰度吗？

可以选择「最高可用清晰度」或「默认原始规格」。可用规格由作品本身提供，不保证每条视频都有相同分辨率或多个规格。

## 下载中断后要重新开始吗？

到下载中心查看任务或批次，点击继续或重试。重启软件后先完成在线检查并按需重新连接微信，再继续任务。

已完成且文件仍完整的结果可跳过；文件被删除、移动或任务未完成时，软件可能需要重新处理。

## 文件保存在哪里？更换目录会移动旧文件吗？

默认保存位置在首页和设置中查看。下载中心每条任务都显示自身实际使用的目录，可以打开目录或定位已完成文件。

更改默认保存目录不会自动迁移旧任务和已有视频。

## 便携版为什么打不开或提示缺少后台程序？

请完整解压便携 ZIP，并保留整个程序目录；主程序和 `video-engine.exe` 需要一起分发。不要只复制 EXE，也不要在压缩包中直接运行。

## 连接后其他软件网络异常怎么办？

在下载器中断开连接或正常退出，让软件恢复连接前的代理设置。若同时使用其他代理软件，再检查其连接状态，避免多个工具反复改写同一代理设置。
